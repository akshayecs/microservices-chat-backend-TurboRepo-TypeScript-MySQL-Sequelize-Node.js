# microservices-chat-backend-TurboRepo-TypeScript-MySQL-Sequelize-Node.js

## Description
This is the TurboRepo of scalable backend chat application with Microservice architecture build in TypeScript+Node.js.

## Tech Stack
Node.js, TypeScript,JavaScript, Express, MySQL, JWT, SequelizeORM,

## Features
- Authentication
- Validation
- Error handling
- Role-based access
- Pagination

## Installation
```bash
npm install
npm run dev
